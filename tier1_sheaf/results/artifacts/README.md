# Tier-1 sheaf — figure/artifact source & build folder

This is the **generator output folder** for the Tier-1 sheaf simulation figures, not a
reader-facing paper folder. Scripts under `tier1_sheaf/campaign/` write their `.pdf`/`.png`
output (plus a few `*_meta.json` data records) here. The figures that the papers actually
`\includegraphics` are the **IEEE single-axes build in the `ieee/` subfolder**, which is
mirrored into `papers/lcss_letter/figures/` and `papers/tcns_section8/figures/` under short
canonical names. Most top-level files carry longer descriptive names and are the
**dev / superseded** multi-panel scenario renders that predate (or sit alongside) the
`ieee/` canonical set.

- **L-CSS floor letter** (`papers/lcss_letter/main.tex`): the latency–curvature floor letter,
  Tier-1 numerics.
- **T-CNS Section VIII** (`papers/tcns_section8/section8.tex`): the flagship journal's
  numerical-validation section, **Tier-1 sheaf plant only — no Drake figures here**.
- The RA-L "Blind Harbor" Drake companion is a separate unit and draws nothing from this folder.

Full reader narratives live in the paper figure folders' READMEs
(`papers/lcss_letter/figures/README.md`, `papers/tcns_section8/figures/README.md`).
Epistemic verdicts below are quoted from the ledger `docs/ral_package.md` and the
`docs/reconciliation_2026-07-21.md` note.

## Two objects, never conflated

1. **Error-transport holonomy amplitude** — the object of **Thm 7.2 [PROVEN]**:
   `log Hol = τ² Σ_k α_k [C_j, C_j'] + O(τ³)`. Measured Tier-1 slope **1.999**; symmetric /
   level-set switch-offs are **machine-zero** (ξ=0 literally `0.0`). Formation-invariant
   extension slope **1.9993 ± 0.0000**.
2. **Closed-loop steady-state disagreement `D_ss`** (units **m²**) — **[CONJECTURAL]**.
   Measured Tier-1 slope **1.101 [1.076, 1.125]**; a measured slope in a conjectural regime,
   carried with the R3 caveat, **asserted as NO law** (CI excludes both 1 and 2). A `D_ss`
   fit **never** validates Thm 7.2 and its slope is **never** called a first-order law.

Frame/units throughout: world ENU, metres; SE(2) load pose = (x, y, yaw); `D_ss` in m².

## Data provenance & authenticity

Every one of the **24 top-level figure entries** in the catalogue below now carries a
`*Theory:*` line (the specific paper statement or falsifier it bears on) and a `*Provenance:*`
line assigning exactly one authenticity class. Class counts:

- **[SIM] — 10:** the figure reads (or live-regenerates) a **seeded-rng plant record** — the
  closed-loop `D_ss` production `e3b_production.json` (1584 seeded runs), plus campaign records
  `e6_topology.json`, `e10_dt_sweep.json`, `e3c_robust.json`, `e2_contraction.json`,
  `e3c_symmetry.json`, `e3c_c9b_seeds.json`, and the live seeded `anim_gauge` / floor-protocol
  traced runs. All named `.json` records **confirmed present** on disk under
  `tier1_sheaf/results/`.
- **[DET] — 9:** the figure **recomputes an exact analytic operator** (`holonomy_amplitude_m2`,
  `conjugated_generator`, `two_agent_commutator`, closed-form leading-order bounds) at the fixed
  common twist ξ=(0.4, 0, 0.12), **no randomness**; shape seeds and the sidecar
  `*_meta.json` / `e3a_extension.json` / `e3a_amplitude.csv` records are **confirmed present**.
- **[DIAGRAM] — 5:** schematic / architecture / notation / map renders with **no measured
  data** — `lcss_schematic`, `lcss_transit_scene`, `tcns_plant`, `tcns_architecture`,
  `theorem_map`. Labelled as such; none reads as a measurement.
- **[FLAG] — 0:** **none found.**

**Finding:** every data figure traces to a **committed simulated record on disk** or to a
**deterministic operator recomputation at fixed inputs**; the five diagrams are labelled as
such; **nothing is fabricated.** A seeded `np.random.default_rng(...)` is reproducible
simulation noise = real simulated data, not fabrication. The strip-plot x-jitter in
`tcns_robust` is a display-only device — its y-values are the real `e3c_robust.json`
suppression ratios. The excluded `b3_relpose.py` (WIP, label "synthetic … DESIGN INCOMPLETE")
feeds **no** paper figure. Epistemic guardrail held throughout: the amplitude object
**[PROVEN, thm:floor / thm:floorF]** and the closed-loop `D_ss` **[CONJECTURAL]** are distinct
objects — no `D_ss` fit is captioned as validating a floor theorem, and honest falsifier
verdicts (C7b FALSIFIED, C9b MET, C9c/C19 TRIPPED) are carried verbatim.
